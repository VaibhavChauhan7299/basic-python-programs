## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/VaibhavChauhan7299/basic-python-programs.git
```

### 2. Navigate to the project

```bash
cd basic-python-programs
```

### 3. Run a Python program

```bash
python3 filename.py
```

For example:

```bash
python3 prac.py
```

## 📦 Installing Libraries

For programs using NumPy or Pandas:

```bash
pip install numpy pandas
```

Or, if you are using Python 3:

```bash
pip3 install numpy pandas
```
